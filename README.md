Maternity Claim Checklist
•	Duly filled Claim Form & Photo ID Proof*
•	Original Hospital Bills with detailed breakup*
•	Payment Receipts *
•	Original detailed Discharge Summary (hospital letterhead, doctor signed & sealed)
•	USG Report (pre delivery)*
•	GPLA Status (Gravida, Para, Living children, Abortions)*
•	Treating Doctor's Certificate on obstetric history for any complications.
•	Original Prescriptions & Investigation Reports for the submitted bills.
•	Cancelled Cheque with IFSC / Bank Passbook copy
•	⁠Photo ID proof if claimed amount is above 1 Lakh
