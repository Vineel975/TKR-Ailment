Rule: When lens cost is clearly given in the estimate as breakup in ClaimDocument, let it be <<lenscostInClaimDocument>> and when lens related info is not mentioned in the tariff (only procedure cost is mentioned), 
  1. if <<lenscostInClaimDocument>> is less than 20,000 bring the default lens cost as <<lenscostInClaimDocument>> and not Rs.20000/-
  2. else, bring the default lens cost as 20,000.



a) if in the tariff document have a clear and precise <<Procedurecharge>> with <<lenstype>> combination- then do not bring default lens cost for Rs.20000/-
Ex: Cataract Phaco with aspheric foldable.
b) When lens cost is extracted separately from tariff (eg:7000), then don't bring 20000/- default lens - already we did this i guess.



Lens names:
When names like "Acrysoft,Acryfold,tecnis,technis,Eyehance,Eyhance,RYCF,Soflex,Abott,Abott SensarAlcon,Alcon Acrysoft,IQ Ultraset,Hoya Vivinox,Hoya Aspheric" are found in Tariff file, it means that the rate is inclusive of Lens cost, don't bring in default 20000/-
